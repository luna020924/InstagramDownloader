# Insta Share Downloader

Instagram이나 Twitter/X에서 본 사진과 영상을 안드로이드 폰에 저장할 수 있게 도와주는 앱입니다.

게시물 링크를 복사해서 붙여 넣을 필요 없이, Instagram이나 Twitter/X에서 공유 버튼을 누른 뒤 `Insta Share Downloader`를 선택하면 됩니다. 앱이 링크를 읽고 받을 수 있는 사진이나 영상을 보여주면, 원하는 것만 골라 저장할 수 있습니다.

## 지금 할 수 있는 것

- Instagram 게시물, 릴스, 스토리 사진과 영상을 저장할 수 있습니다.
- Twitter/X 게시물에 올라온 사진과 영상을 저장할 수 있습니다.
- 사진이나 영상이 여러 개 있으면 원래 앱 위에 Android 기본 선택 시트가 뜹니다. 다른 앱 위에 표시 권한은 필요하지 않습니다.
- 선택창에서는 처음에 모든 항목이 체크되어 있고, 필요 없는 것만 빼면 됩니다.
- 일반 폰과 폴더블의 실제 화면 너비에 맞춰 미리보기 열 수가 바뀝니다. 다크 모드와 큰 글자 설정을 지원합니다.
- 받을 항목이 하나뿐이면 선택창 없이 바로 저장합니다.
- Instagram 스토리는 공유한 스토리만 바로 받을 수도 있고, 같은 계정의 다른 현재 스토리까지 보고 고를 수도 있습니다.
- Instagram 파일명은 계정명과 날짜를 기준으로 저장합니다.
- Twitter/X 파일명은 올린 사람 이름과 날짜를 기준으로 저장합니다.
- 사진은 `Pictures/InstaShareDownloader` 폴더에 저장됩니다.
- 영상은 `Movies/InstaShareDownloader` 폴더에 저장됩니다.

## 설치 파일

- 현재 소스 버전: `0.2.0` — 홈과 공유 선택창을 Compose로 개편하고, 화면 너비에 맞는 그리드·다크 모드·저장 진행과 재시도를 추가했습니다. 스토리 인증 수정도 포함합니다.
- 수정본 빌드 파일: `InstaShareDownloader-0.2.0-debug.apk`
- 기존 GitHub 공개 릴리스: `v0.1.0` — 스토리 수정이 포함되기 전 버전입니다.

공개된 설치 파일은 GitHub 릴리스에서 확인할 수 있습니다. `0.2.0`을 직접 만들려면 아래 빌드 방법을 이용하세요.

## 사용 방법

1. 안드로이드 폰에 APK 파일을 설치합니다.
2. 앱을 열고 `Instagram 로그인`을 누릅니다.
3. Instagram에 로그인한 뒤 완료 버튼을 누릅니다.
4. Instagram 또는 Twitter/X에서 저장하고 싶은 게시물의 공유 버튼을 누릅니다.
5. 공유 대상에서 `Insta Share Downloader`를 선택합니다.
6. 여러 사진이나 영상이 뜨면 받을 것만 체크한 뒤 저장을 누릅니다.
7. 저장이 끝나면 `저장한 항목 보기`를 누르거나 갤러리의 `InstaShareDownloader` 앨범을 확인합니다.

앱 홈에서 링크를 붙여 넣어도 됩니다. 저장 중 창을 닫아도 작업은 계속됩니다.
일부 항목을 저장한 뒤 실패하면 이미 저장한 항목을 제외하고 남은 항목만 다시 저장합니다.

## 스토리 저장

Instagram 스토리 링크를 공유하면 앱이 먼저 물어봅니다.

- `공유한 스토리만 저장`: 방금 공유한 스토리만 바로 저장합니다.
- `다른 스토리도 선택`: 그 계정에서 지금 볼 수 있는 다른 스토리까지 보여주고, 원하는 것만 고를 수 있습니다.

## 알아둘 점

- Instagram에 로그인되어 있어야 스토리나 일부 게시물을 받을 수 있습니다.
- 친한 친구에게만 공개된 스토리처럼 접근이 제한된 내용은 저장되지 않을 수 있습니다.
- Instagram과 Twitter/X는 화면 구조가 자주 바뀌기 때문에, 어느 날 갑자기 일부 링크가 안 될 수 있습니다.
- 이 앱은 다운로드를 폰 안에서 처리합니다. 따로 서버를 두지 않습니다.
- 로그인 정보나 쿠키를 외부 서버로 보내지 않습니다.

## 면책 안내

이 저장소의 코드, 앱, 설명은 편의를 위해 공개된 것이며 어떠한 보증도 제공하지 않습니다. 앱이 항상 정상 동작한다거나, 특정 목적에 맞다거나, 문제가 전혀 없다는 보장을 하지 않습니다.

이 앱을 사용하는 과정에서 발생하는 계정 문제, 서비스 약관 위반, 저작권 분쟁, 데이터 손실, 기기 오류, 기타 손해에 대한 책임은 사용자 본인에게 있습니다. 사용자는 자신이 접근하고 저장할 권리가 있는 콘텐츠에 대해서만 이 앱을 사용해야 하며, 각 서비스의 약관과 관련 법을 직접 확인해야 합니다.

이 저장소의 코드나 정보를 사용하면 위 내용을 이해하고 동의한 것으로 봅니다.

## 직접 빌드하기

개발자가 직접 APK를 만들고 싶다면 아래 명령을 사용하면 됩니다.

```bash
./gradlew :app:assembleDebug
```

빌드가 끝나면 APK는 아래 위치에 만들어집니다.

```text
app/build/outputs/apk/debug/InstaShareDownloader-0.2.0-debug.apk
```

## 테스트

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

스토리 인증 헤더·응답 형식·공유한 항목 선택과 게시물 추출을 단위 테스트로 확인합니다.
기기 테스트는 기본적으로 네트워크에 접속하지 않으며, `liveInstagram=true`를 명시한 경우에만 기기의 기존 로그인 세션으로 조회합니다.
`downloadMedia=true`를 추가하면 사진과 동영상을 임시 저장해 파일을 확인한 뒤 해당 테스트 파일만 삭제합니다.
실제 세션값과 미디어 주소는 테스트 출력에 기록하지 않습니다.

Compose 기기 테스트는 항목 선택·빈 선택의 저장 방지·실패 후 재시도·화면 재생성 시 입력 보존을 확인합니다.
`LiveShareUiTest`는 기존 로그인으로 실제 공유 선택창과 화면 재생성 후 선택 보존을 확인하며,
`downloadMedia=true`일 때 새 저장 흐름으로 한 항목을 저장하고 파일을 확인한 뒤 그 URI만 정리합니다.
`foldStates`에 기기의 상태 번호를 전달하면 화면 전환 중 선택 보존도 확인하고, 끝난 뒤 상태 재정의를 해제합니다.
실제 계정이 포함된 화면 캡처는 기기의 앱 내부에만 저장되며 저장소에 포함하지 않습니다.
